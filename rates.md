# Rates

The following are the **current published server rates** for Return of Midgard.

## Experience Rates

| Rate | Setting |
| --- | --- |
| **Base EXP** | **x100** |
| **Job EXP** | **x100** |

## Monster Drop Rates

| Monster Category | Drop Rate | Status |
| --- | --- | --- |
| **Normal Monsters** | **90%** | Current published setting |
| **Boss (MVP) Monsters** | **x1** | Confirmed |
| **Mini-Boss Monsters** | **Under Review** | Not yet finalized |

**Important:** The normal monster drop setting and the Boss (MVP) drop rate are separate. The **90%** normal monster setting does not apply to Boss (MVP) drops.

### Mini-Boss Drop Rate

The Mini-Boss drop rate is **still under review**. We will update this section once the setting has been finalized.

## Rate Updates

Rates may be adjusted as the server is refined. Any changes will be announced and reflected in this Wiki.

For more details on gameplay rules and server customizations, see [Server Information](server-information.md) and [Official Behavior & Server Customizations](official-behavior-and-customizations.md).
