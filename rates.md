# Rates

The following are the **current published server rates** for Return of Midgard.

## Experience Rates

| Rate | Setting |
| --- | --- |
| **Base EXP** | **x100** |
| **Job EXP** | **x100** |

## Monster Drop Rates

| Monster Category | Drop Rate | Status |
| --- | --- | --- |
| **Normal Monsters** | **90%** | Current published setting |
| **Boss (MVP) Monsters** | **x1** | Confirmed |
| **Mini-Boss Monsters** | **x1** | Confirmed |

**Important:** The **90%** normal monster drop setting is separate from the **x1** Mini-Boss and Boss (MVP) drop rates.

The [official Game Database](https://romidgard.com/database/) provides monster and item drop information. Listed base drop chances are separate from the server-adjusted settings above.

## Rate Updates

Rates may be adjusted as the server is refined. Any changes will be announced and reflected in this Wiki.
