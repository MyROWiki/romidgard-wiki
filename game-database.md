# Game Database

The **Return of Midgard Game Database** is our official website reference for monsters and items in the classic Episode 12 world.

[Open the Game Database](https://romidgard.com/database/)

## Monster Database

Search by monster name or ID to find monster stats, elements, drops, spawn maps, spawn quantities and respawn information. Monster drops link to their item details. MVP and Mini-Boss monsters are identified separately.

## Item Database

Search by item name or ID, or browse by item type. Item details include descriptions, monster drop sources, buy and sell prices, and official NPC shop locations where available. Supported boxes also show their reward lists.

## Important Notes

- The database focuses on the server's Episode 12 monster and item data.
- Custom Prontera NPC Shops, including the Supplies Shop, are not included in the database's official NPC shop listings. See [Prontera NPC Shops](prontera-npc-shops.md) for details.
- Refer to [Rates](rates.md) for current server drop settings. Listed base drop chances should not be confused with server-adjusted drop chances.
- Some images and details may be unavailable or updated as development continues.

For gameplay guides, visit [Game Information](game-information.md).
