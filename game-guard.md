# Game Guard — Raven Shield

**Return of Midgard uses Raven Shield as its game protection and anti-cheat system.**

Raven Shield is part of our effort to maintain a fair playing environment and discourage unauthorized tools or modifications that provide an unfair advantage.

## Playing with Raven Shield

- Download the game client only from the [official Download page](https://romidgard.com/home/download).
- Run the official patcher and complete all updates before launching the game.
- Avoid modifying the game executable or using unauthorized third-party programs while playing.
- If you encounter a Game Guard warning or have trouble starting the client, contact the staff through our [official Discord](https://romidgard.com/discord) and include the exact error message or a screenshot.

## Fair Play

Players are expected to follow the server rules and play without cheating tools, automation, or exploits. Using Raven Shield does not replace the responsibility to follow our fair-play policies.

For installation and patching instructions, see [Getting Started](getting-started.md).
